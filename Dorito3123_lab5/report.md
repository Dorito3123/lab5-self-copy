# Эксперименты — лабораторная №14

Датасет: 50 000 документов (Stack Overflow Questions.csv).
Запустить: `make bench`

## 3.1 Время индексации

`./app index --limit=N`, замер через clock_gettime.

| Документов | AVL (с) | Red-Black (с) | B-tree (с) |
|---|---|---|---|
| 10 000 | 0.272 | 0.304 | 0.279 |
| 30 000 | 0.893 | 0.999 | 0.909 |
| 50 000 | 1.535 | 1.697 | 1.606 |

AVL чуть быстрее RB при вставке — в RB больше перекрашиваний. B-tree примерно посередине.

## 3.2 Время поиска

1000 запросов, `./app bench --words=N`.

| Слов | AVL (мс) | Red-Black (мс) | B-tree (мс) |
|---|---|---|---|
| 1 | 0.0594 | 0.0602 | 0.0596 |
| 2 | 1.4325 | 1.4057 | 1.4167 |
| 3 | 1.2626 | 1.2726 | 1.2665 |

Однословный поиск — один lookup O(log n), почти мгновенно. При двух-трёх словах основные расходы — пересечение posting list'ов, а не обход дерева.

## 4. Fuzzy Search

Реализовано в `index/search.c`. `fuzzyFindCandidates` обходит всё дерево и считает расстояние Левенштейна для каждого ключа. `fuzzySearch` для каждого токена запроса собирает кандидатов, потом ранжирует документы по `score = matched * 10 - avg_distance`.

```bash
./app search --type=avl --fuzzy --max-dist=2 "pythn lst"
./app search --type=rb  --fuzzy --max-dist=1 "sortig"
```

| Режим | Запрос | Время | Найдено |
|---|---|---|---|
| exact | "python list" | 1.5 мс | 202 |
| fuzzy dist=1 | "pythn list" | ~750 мс | ~11000 |
| fuzzy dist=2 | "pythn lst" | ~1470 мс | ~46000 |

Fuzzy медленнее из-за полного обхода дерева — O(уникальных термов) × O(len²).
